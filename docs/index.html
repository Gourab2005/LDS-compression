Physical Deployment Topology

What Lives on the Edge Device vs. Receiver Server

A production IoT deployment does not clone git repos or execute build tools on the edge. The system is split strictly into sender and receiver responsibilities.

Edge Device (Sender)
Automotive ECU • ESP32 • STM32 • Gateway
1. lds.h (Single 5 KB C API header)
2. liblds.a (45 KB static lib linked into firmware)
   — OR —
3. lds_encoder_engine (160 KB standalone binary)
Excluded from Edge: No Git repos, no npm packages, no Python runtime requirements, no compilers. Only the compiled encoder logic is deployed.
Cloud Ingestion (Receiver)
API Gateway • Docker Container • ClickHouse Ingest
1. lds_decoder_engine (Standalone decompression daemon)
2. HTTP / MQTT Ingestion Endpoint (Receives wire hex)
3. Log Store Destination (S3, ClickHouse, OpenSearch)
Server Impact: Near-zero CPU utilization. Decompression operates at >110,000 lines/second per thread, emitting 100% bit-exact log strings.
Implementation Guide

Multi-Language Minimal Integration

Both engines run as persistent subprocesses over OS pipes. Switch between real-time streaming and batched transport block modes below.

Where and How to Configure Batch Size:

In Batched Block mode, you control the batch size directly in your code via two explicit placeholders at the top of each script, or via the command line:

1. BATCH_TARGET_BYTES
Byte threshold. Change to 1024 * 1024 (1 MB for Cloud/Edge Gateway) or 64 * 1024 (64 KB for MCUs / LoRaWAN).
2. MAX_FLUSH_LINES
Line count threshold. Change to 500 or 1000 lines. Forces a block flush when log rate is low.
3. CLI: --batch-size=<bytes>
Pass directly to engine: --batch-size=1048576 (1 MB) or --batch-size=65536 (64 KB).

1 Batched Block Mode Concept

Buffers arrays of 100–1,000 log lines into one binary transport block. Eliminates 99% of per-message HTTP headers.

2 Batched Block Compression Code
import subprocess, json

# -------------------------------------------------------------
# 1. CONFIGURE BATCH SIZE HERE (Adjust to your requirements)
# -------------------------------------------------------------
BATCH_TARGET_BYTES = 1024 * 1024  # 1 MB block target (e.g. 64*1024 for 64 KB MCU)
MAX_FLUSH_LINES    = 2000         # Max lines accumulated before forced block flush

# 2. Spawn LDS batch block engine with configured threshold
encoder = subprocess.Popen(['./bin/lds_encoder_engine.exe', '--mode=batch', f'--batch-size={BATCH_TARGET_BYTES}'],
                           stdin=subprocess.PIPE, stdout=subprocess.PIPE, text=True)

def compress_batch(log_lines: list) -> dict:
    payload = "\n".join(log_lines) + "\n---END_BLOCK---\n"
    encoder.stdin.write(payload)
    encoder.stdin.flush()
    return json.loads(encoder.stdout.readline())

# 3. Buffer lines and dispatch once threshold reached
batch_buffer = [f"2026-10-05 02:00:03.{i:03d} INFO CAN-GW speed={50+i%10}km/h" for i in range(500)]
block_res = compress_batch(batch_buffer)
print(f"Batched {len(batch_buffer)} lines: {block_res['raw_bytes']}B -> {block_res['comp_bytes']}B ({block_res['saving_pct']}% saved)")

const { spawn } = require('child_process');
const readline = require('readline');

// 1. Launch persistent native LDS encoder engine
const encoder = spawn('./bin/lds_encoder_engine.exe');
const rl = readline.createInterface({ input: encoder.stdout });

function compressLine(logLine) {
  return new Promise((resolve) => {
    rl.once('line', (line) => resolve(JSON.parse(line)));

1 Batched Block Transport

Compresses a collection of log records into one single binary block.

2 Batched Block Compression Code
const { spawn } = require('child_process');
const readline = require('readline');

// -------------------------------------------------------------
// 1. CONFIGURE BATCH SIZE HERE (Adjust to your requirements)
// -------------------------------------------------------------
const BATCH_TARGET_BYTES = 1024 * 1024; // 1 MB target (use 64*1024 for 64 KB block)
const MAX_FLUSH_LINES    = 1000;        // Force flush if line count reached first

// 2. Launch engine with configured batch size
const batchEncoder = spawn('./bin/lds_encoder_engine.exe', ['--mode=batch', `--batch-size=${BATCH_TARGET_BYTES}`]);

const rl = readline.createInterface({ input: batchEncoder.stdout });

function compressBlock(logLinesArray) {
  return new Promise((resolve) => {
    rl.once('line', (res) => resolve(JSON.parse(res)));
    batchEncoder.stdin.write(logLinesArray.join('\n') + '\n---END_BLOCK---\n');
  });
}

// 3. Dispatch array of buffered records as ONE payload
(async () => {
  const records = Array.from({ length: 1000 }, (_, i) => `2026-10-05 02:00:01.${i} INFO BMS pack=HV01 temp=42C`);
  const block = await compressBlock(records);
  console.log(`Batched ${records.length} logs: ${block.raw_bytes}B -> ${block.comp_bytes}B (${block.saving_pct}% saved)`);
})();

1 Batched Buffer Concept

Collects multiple events in an in-memory buffer before dispatching as a unified block.

2 Batched Block Compression Code
package main

import (
    "bufio"
    "encoding/json"
    "fmt"
    "os/exec"
    "strings"
)

// -------------------------------------------------------------
// 1. CONFIGURE BATCH SIZE HERE (Adjust to your requirements)
// -------------------------------------------------------------
const BatchTargetBytes = 1024 * 1024 // 1 MB target (use 64*1024 for 64 KB MCU)
const MaxFlushLines    = 1000        // Force flush if line count reached first

type BatchResult struct {
    RawBytes  int     `json:"raw_bytes"`
    CompBytes int     `json:"comp_bytes"`
    Savings   float64 `json:"saving_pct"`
}

func main() {
    // 2. Launch engine with configured batch size
    cmd := exec.Command("./bin/lds_encoder_engine.exe", "--mode=batch", fmt.Sprintf("--batch-size=%d", BatchTargetBytes))
    stdin, _ := cmd.StdinPipe()
    stdout, _ := cmd.StdoutPipe()
    scanner := bufio.NewScanner(stdout)
    cmd.Start()

    // 3. Buffer lines up to MaxFlushLines or BatchTargetBytes
    var buf strings.Builder
    for i := 0; i < 500; i++ {
        buf.WriteString(fmt.Sprintf("2026-10-05 03:00:01.%03d INFO SENSOR temp=24.5C\n", i))
    }
    buf.WriteString("---END_BLOCK---\n")

    stdin.Write([]byte(buf.String()))
    if scanner.Scan() {
        var res BatchResult
        json.Unmarshal(scanner.Bytes(), &res)
        fmt.Printf("Batch Block: %dB -> %dB (%.1f%% saved)\n", res.RawBytes, res.CompBytes, res.Savings)
    }
}

use std::io::{BufRead, BufReader, Write};
use std::process::{Command, Stdio};

// -------------------------------------------------------------
// 1. CONFIGURE BATCH SIZE HERE (Adjust to your requirements)
// -------------------------------------------------------------
const BATCH_TARGET_BYTES: usize = 1024 * 1024; // 1 MB target (use 64*1024 for 64 KB MCU)
const MAX_FLUSH_LINES: usize    = 1000;        // Max lines before forced flush

fn main() -> Result<(), Box<dyn std::error::Error>> {
    // 2. Launch engine with configured batch size
    let mut child = Command::new("./bin/lds_encoder_engine.exe")
        .arg("--mode=batch")
        .arg(format!("--batch-size={}", BATCH_TARGET_BYTES))
        .stdin(Stdio::piped()).stdout(Stdio::piped()).spawn()?;

    let mut stdin = child.stdin.take().unwrap();
    let mut reader = BufReader::new(child.stdout.take().unwrap());

    // 3. Buffer lines and send bounded block
    for i in 0..500 {
        writeln!(stdin, "2026-10-05 02:00:01.{:03} INFO CAN-GW speed=55km/h", i)?;
    }
    writeln!(stdin, "---END_BLOCK---")?;

    let mut result_json = String::new();
    reader.read_line(&mut result_json)?;
    println!("Batched Transport Block: {}", result_json.trim());
    Ok(())
}

import java.io.*;

public class LDSBatchClient {
    // -------------------------------------------------------------
    // 1. CONFIGURE BATCH SIZE HERE (Adjust to your requirements)
    // -------------------------------------------------------------
    static final int BATCH_TARGET_BYTES = 1024 * 1024; // 1 MB target (or 64*1024 for 64 KB MCU)
    static final int MAX_FLUSH_LINES    = 1000;        // Max lines before forced flush

    public static void main(String[] args) throws Exception {
        // 2. Launch engine with configured batch size
        Process proc = new ProcessBuilder(
            "./bin/lds_encoder_engine.exe", 
            "--mode=batch", 
            "--batch-size=" + BATCH_TARGET_BYTES
        ).start();
        BufferedWriter writer = new BufferedWriter(new OutputStreamWriter(proc.getOutputStream()));
        BufferedReader reader = new BufferedReader(new InputStreamReader(proc.getInputStream()));

            writer.write("2026-10-05 02:00:01." + i + " INFO TELEMETRY battery=98% temp=31.2C\n");

        writer.write("---END_BLOCK---\n");
        writer.flush();

        String blockResponse = reader.readLine();
        System.out.println("Compressed Batch Block: " + blockResponse);
        proc.destroy();
    }
}

1 Direct Batched Block API

Calls lds_encode_block() to pack an array of log lines into one binary packet.

2 Batched Block API Code
#include "lds.h"
#include <stdio.h>
#include <stdlib.h>

// -------------------------------------------------------------
// 1. CONFIGURE BATCH SIZE HERE (MCU SRAM / Transport MTU target)
// -------------------------------------------------------------
#define BATCH_TARGET_BYTES  (64 * 1024)  // 64 KB transport block size
#define BATCH_MAX_LINES     500          // Max lines to accumulate in buffer

void send_telemetry_batch(const char** log_lines_array, size_t line_count) {
    static LDSEncoder* enc = NULL;
    if (!enc) enc = lds_encoder_create();

    // Guard line count against configured batch limit
    if (line_count > BATCH_MAX_LINES) {
        line_count = BATCH_MAX_LINES;
    }

    // 2. Compress array of lines into ONE single binary transport block
    size_t block_bytes = 0;
    uint8_t* block_pkt = lds_encode_block(enc, log_lines_array, line_count, &block_bytes);

    // 3. Transmit single block over cellular HTTP POST / LoRaWAN frame
    printf("Batched %zu lines into %zu bytes single transport block\n", line_count, block_bytes);

    // 4. Free block buffer
    free(block_pkt);
}

C99 Standard Specification

Direct C Header API Integration

For bare-metal MCUs and RTOS architectures without process isolation, call the C library functions directly from lds.h. 

#include "lds.h"

// -------------------------------------------------------------
// 1. CONFIGURE BATCH CAPACITY & MEMORY BUDGET
// -------------------------------------------------------------
#define BATCH_TARGET_BYTES  (64 * 1024)  // 64 KB transport block size
#define BATCH_MAX_LINES     500          // Maximum lines per block

// 2. Initialization (Boot sequence)
LDSEncoder* enc = lds_encoder_create(); // Preallocates fixed memory pool (~166 KB)
LDSDecoder* dec = lds_decoder_create(); // Receiver side decoder pool

// 3. Line-by-line online streaming
size_t wire_len = 0;
uint8_t* wire_pkt = lds_encode_line(enc, log_string, &wire_len);
char* restored_log = lds_decode_line(dec, wire_pkt, wire_len);

// 4. Batched block mode (Configured by BATCH_MAX_LINES / BATCH_TARGET_BYTES)
size_t block_bytes = 0;
uint8_t* block_pkt = lds_encode_block(enc, log_lines_array, BATCH_MAX_LINES, &block_bytes);
size_t out_count = 0;
char** restored_lines = lds_decode_block(dec, block_pkt, block_bytes, &out_count);

// 5. Memory cleanup
lds_free_lines(restored_lines, out_count);
free(wire_pkt);
free(block_pkt);
lds_encoder_free(enc);
lds_decoder_free(dec);
